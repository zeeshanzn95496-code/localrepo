# Mercedes-Benz Web Project

A modern and responsive website made for Mercedes-Benz, celebrating 140 years of automotive history from 1886 to 2026.

## About The Project

This website showcases Mercedes-Benz luxury cars, modern vehicle technology, and a complete historical timeline. It includes car specification pages, video previews, interactive search functionality, advanced animations, and a theme switcher for dark and light modes.

## Main Features

### 1. Home Page (index.html)
- A hero header welcoming visitors with glitch text effect on hover.
- A featured video section showcasing the Mercedes-Maybach SL 680.
- An overview of the MBUX infotainment system.
- A test drive booking form where users can select their favorite model.
- Back to top button for easy navigation.

### 2. Models and Detail Pages (models.html)
- A clean grid displaying popular Mercedes-Benz cars with advanced hover effects:
  - 3D card tilt effect on hover
  - Image zoom and overlay animations
  - Shine and glow effects
  - Glitch text effect on car names (hover on text)
- Real-time search bar to filter models by name
- Clicking any car opens a dedicated details page with full specifications:
  - Mercedes-Benz GLC 43 AMG
  - Mercedes-Benz S-Class
  - Mercedes-Benz GLS 450d
  - Mercedes-AMG C 63 S E-Performance
  - Mercedes-AMG CLS 63
  - Mercedes-Benz CLA Sedan
  - Mercedes-Benz A-Class
  - Mercedes-Benz C 220
  - Mercedes-AMG GT
  - Mercedes-Benz V-Class
  - Mercedes-Benz GLE
  - Mercedes-AMG G 63
- Each car page shows engine power, top speed, acceleration, color choices, optional features, and a photo gallery.
- Glitch text effect on hero titles (green, black, blue colors)
- Back to top button on all detail pages

### 3. History Timeline (about.html)
- Covers 140 years of history from 1886 to 2026 across 28 time periods.
- Includes historical photos and milestones, from the first Benz Motorwagen to modern electric cars.
- Era-based navigation with smooth scrolling.

### 4. Vision Cars (vision-cars.html)
- A dedicated page in the navigation bar opening in a new tab.
- Currently under construction for concept vehicles.
- Elegant "Coming Soon" design with shimmer effects.

### 5. Maybach Section (maybach.html)
- Dedicated Maybach luxury section.
- Currently under construction with elegant design.
- Features shimmer gradient text and pulsing badge animations.
- Styled with the same premium aesthetic as Vision Cars.

### 6. Interactive Features
- **Search Bar**: Real-time model filtering on the models page
- **Glitch Text Effect**: Cool text animation on hover (green, black, blue colors)
- **3D Card Tilt**: Premium 3D rotation effect on model cards
- **Enhanced Hover Effects**: Image zoom, shine effects, glow borders
- **Back to Top Button**: Floating button on all pages for easy navigation
- **Smooth Scrolling**: CSS smooth scroll for all anchor links

### 7. Dark and Light Mode (theme.js)
- Easy one-click button to switch between dark mode and light mode.
- Smooth transition animation when changing themes.
- Remembers your selected theme even after closing or refreshing the browser.
- Consistent theme across all pages.

## Technologies Used

- HTML5: Page structure and content.
- CSS3: Custom styling, responsive layouts, and animations.
  - style.css: Main design and theme colors.
  - model.css: Car grid, detail page styling, search bar, glitch effects, 3D tilt.
  - about.css: History timeline design.
  - vision.css: Vision Cars page styling and text decorations.
  - maybach.css: Maybach page styling with shimmer effects.
- JavaScript: Theme switching and search functionality.
- Bootstrap 5: Responsive layout and mobile navigation menu.

## How to Run

You do not need to install anything to view this project.

1. Download or clone this folder.
2. Double-click `index.html` to open it directly in your web browser (Chrome, Edge, Firefox, or Safari).
3. Alternatively, open the folder in VS Code and use the Live Server extension.
